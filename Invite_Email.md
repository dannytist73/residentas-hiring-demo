# TEST INVITE
As the next step, we would like to invite you to complete a paid practical test.

The goal is to assess how you think about workflows, automation, and process design, through a task that closely reflects the type of work expected in the role.

 Test objective

Create a simple and reusable workflow that can:

receive candidate data from a form or structured dataset
evaluate the candidate using a scorecard
assign an outcome
generate the appropriate follow-up email
be reusable for future candidates with minimal manual work
 

What we are looking for

clarity and structure in your workflow design
thoughtful choice of tools and rationale
solid decision logic and evaluation approach
a solution that is reusable, not a one-off
 

Expected deliverables (all required)

A short written summary of the workflow
A working prototype or clear mock-up
A brief explanation of the scorecard and decision logic
Example outputs for different candidate outcomes
A short note on how the workflow could be improved or reused
 

Important

Please do not use real company systems or request access to internal tools
Use only sample or dummy data
Keep the solution practical and proportionate
Please use the attached files as the base input for your solution
You are free to use any tools, including AI tools (e.g. Claude, ChatGPT, etc.)
You may implement this using automation tools, workflows, or agent-based approaches
The solution should be designed so that it can process future candidates without needing to be rebuilt
